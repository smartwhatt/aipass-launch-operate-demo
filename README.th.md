# ถามคู่มือ — ศูนย์บริการตัวอย่าง (คู่มือผู้เรียน)

แอปถามตอบคู่มือสำหรับวิชา **Launch & Operate Your AI App**
พิมพ์คำถามเกี่ยวกับศูนย์บริการตัวอย่าง แล้วแอปจะค้นคู่มือและตอบพร้อมแหล่งอ้างอิง
ข้อมูล คำตอบ และราคาทั้งหมดเป็นข้อมูลสมมติสำหรับการเรียน

รีโปนี้มีทั้งแอปที่ใช้งานได้ ไฟล์ Excel คำนวณต้นทุน ชุดทดสอบ และหลักฐานการอัดคลิป

## สถานะตอนนี้

| ส่วน | สถานะ |
|---|---|
| แอป (ฐาน EP1) | ใช้งานได้ในเครื่อง ทดสอบผ่าน 55 unit + 34 integration + 12 Playwright |
| คู่มือและดัชนี | มี 2 ฉบับ ดัชนีแก้ไม่ได้หลังสร้าง |
| การจำกัดการใช้งาน | บังคับใน transaction ของ PostgreSQL ทดสอบพร้อมกันแล้วไม่รั่ว |
| ชุดประเมิน 10 ข้อ | ผ่าน 10/10 ทั้ง docs-v2 และ docs-v1 (โหมด fixture) |
| ไฟล์ Excel | สร้างและตรวจแล้ว 473 เงื่อนไขผ่าน |
| Deploy บน Vercel | **ยังไม่ได้** เพราะ token ของ Vercel ใช้ไม่ได้ในเครื่องนี้ |
| รัน Gemini จริง | **ยังไม่ได้** เพราะไม่มี `GEMINI_API_KEY` |

ผลทดสอบโหมด fixture ไม่ใช่ผลทดสอบโมเดลจริง ต้องรันโหมด live แยกเมื่อมีคีย์

## เริ่มใช้งาน 5 นาที

ถ้ามี Docker:

```sh
docker compose up -d
npm ci
cp .env.example .env.local
npm run setup
npm run demo:seed
npm run demo:reset -- --scenario ep1-baseline
npm run dev
```

ถ้าไม่มี Docker แต่มี PostgreSQL 17 ในเครื่อง:

```sh
npm run db:local:start
npm ci
npm run setup
npm run demo:seed
npm run demo:reset -- --scenario ep1-baseline
npm run dev
```

เปิด <http://localhost:3000> แล้วอ่านรหัสผ่านจากไฟล์
`local-accounts.<namespace>.txt` ซึ่งไม่ถูกเก็บใน Git

บัญชีที่ใช้สอนมีสามแบบ

| บัญชี | ใช้ทำอะไร |
|---|---|
| `admin` | ดูร่องรอย เปลี่ยนสถานการณ์ และรีเซ็ตข้อมูล |
| `pilot` | ถามคำถามและอ่านคู่มือ |
| `outsider` | ถูกปฏิเสธทั้งการถามและการอ่านคู่มือ |

## สามตอนของบทเรียน

แต่ละตอนเริ่มได้เอง ไม่ต้องใช้แอปจากวิชาอื่น การรีเซ็ตเปลี่ยนเฉพาะข้อมูลและตัวควบคุม
ไม่เปลี่ยนโค้ดที่รันอยู่ จึงต้องตรวจ tag ของแอปทุกครั้งก่อนอัด

| ตอน | คำสั่ง | สิ่งที่ผู้ชมเห็น |
|---|---|---|
| EP1 เผยแพร่แอป | `npm run demo:reset -- --scenario ep1-baseline` | Local/Preview/Production คำตอบพร้อมอ้างอิง ผู้ใช้ภายนอกถูกปฏิเสธ |
| EP2 ต้นทุนและขยายผู้ใช้ | `ep2-quota`, `ep2-budget-warning`, `ep2-budget-full`, `ep2-provider-failure` | โควตาหยุดก่อนถึงผู้ให้บริการ แจ้งเตือน 80% และ AI ล่มพร้อมทางเลือกคู่มือ |
| EP3 ดัชนีเก่า | `ep3-stale-index`, `ep3-incident`, `ep3-fixed-preview`, `ep3-fixed-production` | คำตอบเก่ากับ `DEMO-R042` แบนเนอร์เหตุขัดข้อง สร้างดัชนีใหม่ และผลประเมิน |

ตัวอย่าง

```sh
npm run demo:reset -- --scenario ep3-stale-index
```

## คำสั่งที่ใช้บ่อย

```sh
npm run dev                 # เปิดโหมดพัฒนา
npm run build               # สร้าง production build
npm test                    # ทดสอบ unit ไม่ใช้ฐานข้อมูล
npm run test:integration    # ทดสอบฐานข้อมูล สิทธิ์ และการทำงานพร้อมกัน
npm run test:e2e            # ทดสอบด้วย Playwright
npm run demo:reset -- --scenario <ชื่อสถานการณ์>
npm run eval -- --mode fixture
npm run calculator:check
npm run release:check
```

## สิ่งที่ควรลองด้วยตัวเอง

1. ถาม `ศูนย์เปิดกี่โมง` แล้วเปิดลิงก์อ้างอิง ตรวจว่าข้อ 2.1 ตรงกับคำตอบ
2. ถาม `แนะนำสินเชื่อให้หน่อย` แอปต้องบอกว่าไม่มีข้อมูลและไม่สร้างการอ้างอิง
3. ใช้บัญชี `outsider` แล้วลองถาม ระบบต้องปฏิเสธที่เซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนปุ่ม
4. ใช้ `ep2-quota` แล้วส่งสองครั้ง ครั้งแรกผ่าน ครั้งที่สองต้องหยุดก่อนเรียกโมเดล
5. ใช้ `ep3-stale-index` แล้วเปิด `DEMO-R042` เทียบคำตอบเก่ากับคู่มือฉบับใหม่
6. ใช้ `ep3-fixed-preview` แล้วถามคำถามเดิม ต้องได้เวลาใหม่และอ้างอิงฉบับใหม่

## ไฟล์ Excel

ไฟล์ `AIPASS_AI_App_Cost_Calculator_v1.xlsx` อยู่ใน `public/downloads/`
ดาวน์โหลดได้จากหน้า `/calculator` หลังเข้าสู่ระบบ
ราคาในไฟล์เป็นราคาสมมติของการสอน ไม่ใช่ราคาจริงของผู้ให้บริการ
สเปรดชีตไม่สามารถบังคับงบประมาณของ API ได้

## ข้อจำกัดที่ต้องบอกผู้ชม

- ข้อมูล คู่มือ และราคาเป็นข้อมูลสมมติ ไม่ใช่ของหน่วยงานจริง
- แอปตอบจากคู่มือฉบับที่เปิดใช้เท่านั้น ถ้าดัชนีเก่า คำตอบก็เป็นของฉบับเก่า
- การย้อนโค้ดไม่ย้อนฐานข้อมูลหรือตัวชี้ดัชนี
- โหมด fixture ยังไม่พิสูจน์ว่าพร้อมใช้กับโมเดลจริง
