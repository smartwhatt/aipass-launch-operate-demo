# ชุดส่งต่องานเดโม AIPASS

เริ่มที่ `AGENTS.md` และ `IMPLEMENTATION_SPEC.md` เพื่อให้ AI agent สร้างแอปและไฟล์ Excel ตามบทวิดีโอทั้ง 3 ตอน

สถานะรอบนี้: มีสเปกภาษาอังกฤษ ข้อมูลตัวอย่าง และรายการตรวจแล้ว แอป ไฟล์ Excel และเว็บเดโมยังต้องสร้างตามสเปก

ตรวจชุดข้อมูลที่แนบด้วยคำสั่งนี้ได้ โดยใช้ Python 3:

```sh
python3 tools/validate_handoff.py
```

`docs/VIDEO_DEMO_MATRIX.md` เชื่อมแต่ละช่วงของวิดีโอกับหน้าจอและผลที่ต้องเห็น ส่วน `docs/RECORDING_RUNBOOK.md` ระบุวิธีเตรียมและคืนสถานะก่อนอัดซ้ำ

ราคาที่ใช้คำนวณเป็นราคาสมมติสำหรับบทเรียน ข้อมูลคู่มือและเหตุการณ์ทั้งหมดเป็นข้อมูลสมมติ

เมื่อสร้างเสร็จแล้ว ผู้พัฒนาต้องเพิ่มวิธีติดตั้งภาษาไทย ลิงก์เว็บเดโม และไฟล์ Excel ที่ทดสอบแล้วก่อนแจกให้ผู้เรียน
